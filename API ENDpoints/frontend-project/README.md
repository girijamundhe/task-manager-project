# Task Manager API Documentation

## API Endpoints

### Get Tasks
GET /tasks

Returns all tasks.

### Filter Tasks
GET /tasks?status=completed

Returns completed tasks.

### Sort Tasks
GET /tasks?sort=title

Returns sorted tasks.
